## 図1 — 家格ピラミッド

佐賀藩の武士の身分序列。典拠は『佐賀市史』第2巻 p.24。

> 武士の身分は、三家・親類・親類同格・連判家老・加判家老・着座・独礼・平侍・
> 手明鑓・徒士・足軽という序列が出来たが、**これも本藩を中心としてみた場合のもので、
> 自治を認められていた大配分では、それぞれ独自の組織をもち、家老その他の職制があった**。

| 序列 | 名称 | 読み | 属する家 | 備考 |
|---|---|---|---|---|
| 1 | 三家 | さんけ | 蓮池鍋島家・小城鍋島家・鹿島鍋島家 | 三支藩。本藩の家中に対して一段上にランクされた |
| 2 | 親類 | しんるい | 白石鍋島家・川久保神代家・久保田村田家 | 本藩当主の一門 |
| 3 | 親類同格 | しんるいどうかく | 諫早家・武雄鍋島家・多久家・須古鍋島家 | **龍造寺一門四家。旧主家の一門でありながら、藩政の最高責任者である請役家老を交代で務めた** |
| 4 | 連判家老 | れんぱんがろう | | 家老クラス |
| 5 | 加判家老 | かはんがろう | | 家老クラス |
| 6 | 着座 | ちゃくざ | | のち「着座一八家」。番方15組の大組頭はこの中から選ばれるのが原則 |
| 7 | 独礼 | どくれい | | 単独で藩主に拝謁できる格 |
| 8 | 平侍 | ひらざむらい | | 一般の侍 |
| 9 | 手明鑓 | てあきやり | | **佐賀藩独特の身分。本藩と蓮池藩に限られた。**元和6年（1620）、勝茂が50石未満の侍200人の平時の役を免じて知行を没収し、代わりに切米15石を一律支給したことに始まる。戦時には鑓一本をもって奉公すると定められた |
| 10 | 徒士 | かち | | 徒歩の下級武士 |
| 11 | 足軽 | あしがる | | 最下層。弓足軽・鉄砲足軽など |

### この図の要点（ここが今回の核心）

上の引用のとおり、**この序列は本藩から見た場合のものにすぎない。**
三支藩・親類・親類同格は独自の着到（軍事編成）を持ち、家老以下の職制を別に持っていた。

つまり**これは単一のピラミッドではない。**
この留保が、注記としてではなく**図そのもので**伝わることを目指してほしい。
「全員が一つの序列に収まっていた」という誤解を与える図は失敗。

### そのほかの要件

- 11段の身分差が**直感的に分かる**こと
- 各段にどの家が属するかが辿れること（クリックで家の個別ページへ飛ぶ）
- 各段の人数比は**史料上の実数ではない**（図示上の目安）。断定的に見せないこと
- 家の登録が増えても破綻しないこと

## 図2 — 職制図

藩の機構は大きく、**軍事の組織である番方**と**行政の組織である役方**に分かれる。
初期の武断的な政治のもとでは番方が重んじられ、幕藩体制の確立後、
文治政治の風潮のなかで役方が重視されるようになった。（『佐賀市史』第2巻 p.24）

### 役方 — 行政（請役所を頂点とする階層）

| 名称 | 読み | 上位 | 定員 | 職掌 |
|---|---|---|---|---|
| **請役所** | うけやくしょ | — | — | 一般行政・渉外・財政・裁判。藩政を総括した最高行政機関 |
| 請役家老（御当役） | うけやくがろう | 請役所 | 1人 | 藩政の総括。**原則として龍造寺一門の親類同格四家から交代で任じられた** |
| 相談役 | そうだんやく | 請役所 | 着座3人・差次2人・役格侍 | 請役家老の補佐 |
| 附役 | つけやく | 請役所 | 侍3人 | 実務補助 |
| 案文方 | あんぶんかた | 請役所 | 書上方より1人を兼帯 | **文書作成。文書行政が独立の機能として組み込まれている** |
| 御蔵方 | おくらかた | 請役所 | — | 一般会計 |
| 懸硯方 | かけすずりかた | 請役所 | — | 別会計。請役所はこの二重会計を監督した |
| 御目安方 | おめやすかた | 請役所 | — | 銀蔵・米蔵の管理 |
| 郡代 | ぐんだい | 請役所 | — | 地方支配 |
| 代官 | だいかん | 郡代 | — | 村方の掌握 |

### 番方 — 軍事（着到を頂点とする別系統）

| 名称 | 読み | 上位 | 定員 | 内容 |
|---|---|---|---|---|
| **着到** | ちゃくとう | — | 15組 | 軍事編成。中世的な呼称。御側4・先手2・警固6・留守居3 |
| 大組頭 | おおぐみがしら | 着到 | 15人 | 各組の指揮。横岳・神代・深堀・太田・倉町・姉川の各鍋島家の家老の家格と、着座一八家から選ばれるのが原則 |

**三支藩・親類・親類同格は、本藩とは別に独自の着到を持っていた。**

### この図の要点

現状は箱を罫でつないだだけで、組織の性格が何も見えない。
以下が**図を見るだけで分かる**ようにしてほしい。

1. **役方と番方が並立している**こと（どちらかが上位ではない）
2. 役方が請役所を頂点とする階層であること
3. 各機関が何をしていたか
4. **文書行政（案文方）が独立した機能として組み込まれている**こと
5. **最高責任者（請役家老）が旧主家一門から出る**という変則

5番について補足すると、佐賀藩の執政構造の最大の特徴はここにある。
藩政の最高責任者を、旧主家である龍造寺氏の一門四家から交代で出させた。
一見厚遇だが、鍋島系の上位家格（三支藩など）は藩政の重責を回避し、
**赤字財政の運営責任を四家に負わせる配置**になっていた。
この「ねじれ」が図に出ると理想的。

## 共通の制約

- **素の HTML + CSS**。動きが要る場合のみバニラ JS。
  React・Tailwind・jQuery・D3 は使わない（Astro に手で移植するため）
- **ライトとダーク両方で成立すること。**
  透明度だけで階層を表す図はダークで潰れるので注意
- **JavaScript 無効でも情報が読めること。** JS は強化であって前提ではない
- **最小 360px まで破綻しないこと。** 狭い画面で情報を `display:none` で消して逃げない
- `prefers-reduced-motion: reduce` で動きを止める。
  動きが情報を伝えている場合、静止状態でも同じ情報が読めること
- 代替テキスト、または同じ内容の表を併置
- **データが増えても自動で育つ構造**にすること。
  この2図はデータベースから生成されるので、要素数が2倍3倍になっても壊れないこと
- 典拠の表示を必ず入れる（『佐賀市史』第2巻 p.24 など）。
  このサイトでは出典表示は必須要素であって、省略できない

## このサイトの原則（図の設計に効く）

- **わからないことはわからないまま置く。** 推定で補完しない
- **現代的な価値判断を持ち込まない。** 身分制度を批判も美化もせず、構造として記述する
- 人数比のように「図示上の目安であって史料上の実数ではない」ものは、
  そうと分かるように示す
