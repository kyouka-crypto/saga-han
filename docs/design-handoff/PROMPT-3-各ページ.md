## 共通の前置き（A〜E すべての冒頭に貼る）

佐賀藩（江戸時代の肥前国の大名家）の研究アーカイブサイトの画面を作り直したい。

読者は**日本史をよく知っている人**。
目標は「800ページの研究書を何冊も読まなければ見えてこない構造を、
出典を示しながら、図とともに解きほぐす」こと。
**難しい内容を、難しいまま、分かりやすく**出す。噛み砕いて薄めるのではない。

運営方針：出典なき記述は載せない／わからないことはわからないまま置く（推定で埋めない）／
現代的な価値判断を持ち込まない。

**制約**：素の HTML + CSS（+ 必要ならバニラ JS）。React・Tailwind・jQuery は使わない。
ライトとダーク両対応。JS 無効でも中身が読める。最小360pxまで破綻しない。
狭い画面で情報を `display:none` で消して逃げない。
`prefers-reduced-motion` で動きを止める。

**この題材には写真が1枚もない。** 画面を持たせるのは図表と文章だけ。
実データを使うこと（ダミーテキストで設計しない）。

## E. 「人物と家」の再構成 ← **構造変更を伴う**

添付：`現状コード/page-人物と家.astro`

**現状**：藩主の表（代数の二つの数え方を併記）＋その他人物のリスト。
索引としても詳細としても中途半端。

### 新しい構造

`/people/` を**検索・索引のページに徹させる**。詳細を置かず、
主要なキーワードごとの個別ページへ送り出すことに専念させる。

送り先：

| グループ | 個別ページ |
|---|---|
| 氏族 | 少弐氏 / 龍造寺氏 / 鍋島氏 |
| 鍋島氏の内訳 | **佐賀鍋島家（本藩）/ 蓮池鍋島家** — それぞれ独立ページ。ほか小城鍋島家・鹿島鍋島家 |

| 親類三家 | 白石鍋島家 / 川久保神代家 / 久保田村田家 |
| 人のまとまり | 藩主 / 幕末の人物 / 明治政府の人物 / 学者・技術者 |

### 索引ページ（`/people/`）の要件

- 検索が主役
- グループごとの入口が一望できる
- ここで詳細を読ませない

### 家の個別詳細ページの要件

基本情報（家格・出自・居所・知行高の推移）に加えて、**地図を入れる**。

地図で示すもの：
- その家の**勢力範囲**（知行地・支配域）
- **関連する場所**（居城・陣屋・屋敷・菩提寺・窯など）
- 時期によって範囲が変わる家は、その変化も

> **重要な制約**：地図の下敷きとなるデータ（郡界・知行地の範囲）はまだ無い。
> 地名も12件中**座標が分かっているのは3件だけ**。
> **範囲が確定できない部分を、推定で塗らずにどう表現するか**を設計に含めること。
> これはこのサイト全体の原則（わからないことはわからないまま置く）の適用でもある。
> 「データが揃うまで地図を出さない」のではなく、
> 「今ある分だけで成立し、増えたら育つ」地図にしてほしい。

### 藩主の代数について（この構造の特徴）

佐賀藩主を何代と数えるかは、基本文献のあいだで一致していない。

- 『佐賀藩の総合研究』『続 佐賀藩の総合研究』… **鍋島直茂を初代**として数える
- 『佐賀市史』… **勝茂を初代**として数える

両者は常に1つずれる（直正は一一代とも十代とも書かれる）。
このサイトはどちらか一方を採らず、**両論を対等に併記する**。
**二つの値を、どちらが正でどちらが副でもなく見せる表現**が要る。

## F. 記事ページの幅（これだけは軽微）

添付：`現状コード/page-記事.astro`

現状のグリッド：

```css
.article-grid {
  grid-template-columns: 220px minmax(0, 720px) 250px;  /* 目次 / 本文 / 欄外注 */
  gap: 56px;
  justify-content: center;
}
```

親が `max-width: 1200px` で頭打ちのため、**本文が720pxまでしか伸びず狭すぎる**。

- `.article-grid` を**画面幅いっぱい、またはPCの最大幅**まで広げる
- **左の目次と右の欄外注は非常に良いので必ず残す**
- 広げた結果、本文の一行が長くなりすぎないよう、文字サイズ・行長・
  カラム幅配分を設計し直す（日本語は一行40〜50字あたりが上限の目安）
- 1439px以下で欄外注を、1023px以下で目次を畳む現在の段階は維持してよい
- **記事には図版が2〜6点挟まる**（現状は0点なので検証されていない）。
  本文中に図が入ったときのレイアウトも設計すること
