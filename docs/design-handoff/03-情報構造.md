## 二つの軸

佐賀藩に対象を絞ると、時代軸だけでは記事を分類できなくなる。
「請役所」は260年を貫いてどの時代にも属さず、逆に主題軸だけでは時系列が失われる。
そこで**時代軸と主題軸を直交させている**。

## データの持ち方

記事のほかに7つのコレクションがある。**図表はこれらから自動生成される**。
手描きの図は作らない方針なので、設計もデータから生成できる形にしてほしい。

| コレクション | 主なフィールド |
|---|---|
| `articles` | title, periods[], theme, kind(A/B/C), sortYear, summary, confidence, sourceRefs[] |
| `people` | name, reading, birth, death, house, reign, **generation（代数を二通り持つ）**, summary |
| `houses` | name, reading, **rank（家格）**, origin, **chigyo[]（年ごとの知行高）**, seat |
| `offices` | name, reading, **branch（番方/役方）**, **parent（上位機関）**, seats, duties[], eligibleRanks[] |
| `events` | year, wareki, title, period, themes[], summary, scope(han/national), weight(1–3) |
| `places` | name, kind, gun, **lat/lng（欠けていることがある）**, modern |
| `terms` | term, reading, definition, themes[] |
| `sources` | title, volume, author, publisher, year, url |

### 記事の型

| 型 | 本文 | 図版 | 想定本数 |
|---|---|---|---|
| A 主題記事 | 2,500〜4,000字 | 4〜6点 | 15 |
| B 標準記事 | 1,500〜2,500字 | 2〜4点 | 70 |
| C 小記事 | 600〜1,200字 | 1〜2点 | 30 |

**1記事あたり図版2〜6点**が前提。記事ページの設計は、
図版が本文に挟まることを織り込んでほしい（現状は図版0点で、
挟まったときのレイアウトが検証されていない）。

## 課題8で作る新しい構造（提案）

`/people/` を索引に徹させ、詳細を個別ページへ逃がす。

```
/people/                     索引・検索（ここが入口）
├─ 氏族・家から
│   ├─ /houses/shoni/        少弐氏
│   ├─ /houses/ryuzoji/      龍造寺氏
│   └─ 鍋島氏
│       ├─ /houses/saga/     佐賀鍋島家（本藩）  ← 独立ページ
│       ├─ /houses/hasuike/  蓮池鍋島家          ← 独立ページ
│       ├─ /houses/ogi/      小城鍋島家
│       └─ /houses/kashima/  鹿島鍋島家
│   ├─ 龍造寺一門四家（多久・武雄・諫早・須古）
│   └─ 親類三家（白石鍋島・川久保神代・久保田村田）
└─ 人のまとまりから
    ├─ 藩主
    ├─ 幕末の人物
    ├─ 明治政府の人物
    └─ 学者・技術者
```

家の個別ページに載せるもの：

1. 基本情報（家格・出自・居所・知行高の推移）
2. **地図**（勢力範囲・関連する場所・時期による変化）
3. 当主の系譜
4. 関連する記事・年表項目

> **地図のデータについて**：近世村領域データから
> 佐賀藩・小城藩・蓮池藩・鹿島藩の村 399件を抽出済み（`src/data/datasets/villages.json`）。
> 398村に座標がある。ただし慶応4年の一断面で、面（ポリゴン）はまだ無く、
> 背景地図も未取得。地図を持てるのは4家のみ。
> 詳細は `PROMPT-3-各ページ.md` の E を参照。
