佐賀藩（江戸時代の肥前国の大名家）の研究アーカイブサイトの**デザインシステム**を作ってほしい。

すでに動いている Astro 製の静的サイトがある：https://dancing-concha-3433eb.netlify.app
**ただしこれが「デザインが全く足りていない」と評価されている状態**なので、参考にはしても踏襲はしないでほしい。

## サイトの性格

鍋島氏による藩政264年（1607頃–1871）を対象に、制度・家臣団・財政・軍事・産業・学問を
**構造として**記述する研究アーカイブ。

読者は**日本史をよく知っている人**。目標は

> 800ページの研究書を何冊も読まなければ見えてこない構造を、
> 出典を示しながら、図とともに解きほぐす

こと。**難しい内容を、難しいまま、分かりやすく**出す。噛み砕いて薄めるのではない。

運営方針として明言されていること：

- 出典なき記述は載せない（全記述に書名・巻・ページを付ける）
- わからないことはわからないまま置く（「未詳」「諸説あり」を明示し断定しない）
- 現代的な価値判断を持ち込まない（善政／悪政ではなく制度と構造を記述する）

## いま何がだめか

**全体が単調で、四角形が多すぎる。**
見出しが四角い枠に囲われ、カードが四角、チップが四角、図表の枠も四角。
どのページも「角丸2〜3pxの矩形が並ぶ」という同じリズムで、
ページごとの性格の違いが視覚的に出ていない。

学術的な密度のあるサイトで矩形だけを並べると、情報量の差が伝わらない。
「ここは一望する場所」「ここはじっくり読む場所」「ここは探す場所」の区別が消えている。

## 作ってほしいもの

### 1. `tokens.css` の差し替え版

下の変数名は**すべて維持**すること（全ページ・全コンポーネントが参照している）。
値は自由に変えてよい。新しい変数を足すのも自由。**名前を消さないこと**が条件。

```
/* 面と文字 */
--paper --paper-2 --paper-3 --card
--ink --ink-2 --ink-3 --ink-4
--rule --rule-2
--navy --shadow --shadow-lg

/* 時代の色 — 8期。時間の並びなので順序が感じられるとよい */
--c-shoni      前史・少弐氏（〜1559）
--c-ryuzoji    前史・龍造寺氏と権力移行（1530–1607）
--c-seiritsu   藩制の成立（1607頃–1657）
--c-kakuritsu  藩制の確立と矛盾（1657–1750）
--c-mosaku     改革の模索（1750–1830）
--c-naomasa    直正の藩政改革（1830–1861）
--c-ishin      幕末維新と藩の終焉（1861–1871）
--c-yoha       余波（1871–1877）

/* 主題の色 — 6系統。並立するカテゴリなので順序を感じさせない方がよい */
--t-seido   制度・職制
--t-kashin  家臣団・身分
--t-zaisei  財政・経済
--t-gunji   軍事・対外
--t-sangyo  土地・産業
--t-bunka   学問・文化・宗教

/* そのページのアクセント（時代／主題に応じて body に差し込まれる） */
--era --era-soft

/* 信頼度バッジ */
--conf-sourced-fg --conf-sourced-bg   出典準拠
--conf-ai-fg      --conf-ai-bg        AI統合・検証中
--conf-note-fg    --conf-note-bg      研究メモ

/* 書体・寸法・動き */
--f-mincho --f-sans --f-en --f-mono
--fs-xs --fs-sm --fs-base --fs-body --fs-lg --fs-h2 --fs-h1 --fs-hero
--leading-body --measure
--w-wide --w-narrow --gutter
--ease-out --dur --cue --cue-step
```

**ライトとダークの両方**を定義すること（`:root` と `:root[data-theme="dark"]`）。
片方だけのデザインは採用できない。

**色の設計で注意**：時代8色と主題6色が同じ画面に同時に出る場面が多い
（俯瞰マトリクス、記事カード、年表）。**14色が喧嘩しないこと**。

### 2. 基本部品

矩形の反復から抜け出した形で、以下を設計してほしい。

- 見出し（h1 / h2 / h3）— **囲わずに**階層を出す方法
- 本文組版（日本語。一行40〜50字が上限の目安）
- カード（記事・人物・家）
- チップ／ラベル（時代・主題・家格）
- **信頼度バッジ 3種**（後述。特殊な要件がある）
- 罫・区切り・余白の体系
- リンク・ボタン
- 表
- 図版の枠とキャプション（出典とライセンスが必ず付く）

### 3. なぜその方向にしたのかの説明

数行でよい。**この題材（武家の制度・身分・軍制）に、なぜその色と書体が合うのか。**

## 制約

- 成果物は**素の CSS**。Tailwind・CSS-in-JS は使わない（Astro に手で移植するため）
- 日本語の**明朝とゴシックの両方**が必要（本文が長く、縦の密度が高い）。
  現在は Shippori Mincho B1 と Zen Kaku Gothic New。変更してよい
- **年号と石高が至るところに出る**。数字の見え方は重要。
  現在は等幅にして「データである」ことを示している
- `prefers-reduced-motion: reduce` ですべての動きを止める
- 本文のコントラスト比 4.5:1 以上
- 最小 360px まで破綻しない
- 色だけで意味を区別しない

## 信頼度バッジについて（特殊な要件）

3段階が**全ページの随所に出る**。

| 表示 | 意味 |
|---|---|
| 出典準拠 | 記述は明示した出典に基づき、人手で照合済み |
| AI統合・検証中 | 出典に基づくがAIによる統合を含む。原典との逐一照合は未了 |
| 研究メモ | 作業仮説・調査途上のメモ。引用非推奨 |

これは飾りではなく、**このサイトの信頼性の根拠そのもの**。
目立たせすぎても、埋もれさせてもいけない。
「ちゃんとしている」という手応えが伝わる程度に、常に視界の端にある状態が理想。

## 参考にしてほしいもの

**https://matsurito.jp/** ——「白背景の硬質な内容でありながら、
誰もが見やすいと思える本格的なデザイン」として挙げられた。目標水準。

実際にCSSを読んだところ、地 `#fff` / 文字 `#212223`（純黒ではない）/
罫線 `#e1e5e9`（非常に淡い）/ 弱い文字 `#21222340` の四値を土台に、
高彩度のアクセント（`#fa3f3d` `#ffe560` `#35db62` `#3cd2fa`）を少量だけ使っている。
書体は Zen Kaku Gothic New 400/700 のみで、欧文書体を足していない。
**囲うのではなく、仕切る**設計になっている。

ただしこれは**写真が主役**のサイト。ここが重要な違いで——

## いちばん難しいところ

**このサイトには写真が1枚もない。当面それは変わらない。**

画面を持たせるのは**図表と文章だけ**。
「写真の代わりに何が画面を持たせるのか」を、デザインシステムの段階で答えてほしい。

あわせて、記事はいま**5本しかない**が目標は115本。
**5本でもスカスカに見えず、115本でも破綻しない**体系が要る。

## 避けてほしいもの

- 軽薄な装飾、ポップな配色（題材に合わない）
- 古めかしい「和風テンプレート」（それも違う）
- 装飾のための装飾

**現代的で、硬質で、密度が高く、それでいて読みやすい**——という線を狙ってほしい。
