# Claude design 引き継ぎ資料

デザインを Claude design で作り直すために、渡すものを一式まとめたフォルダ。

## 使い方

1. **`PROMPT.md` の中身をコピーして Claude design に貼る**
2. 同じ会話に、このフォルダの `01`〜`06` と `現状コード/` を添付する
3. 出てきた成果物をこのフォルダに戻し、VSCode 側で Astro へ移植する

段階を分けて依頼する構成にしてある。いきなり全ページ作らせず、
まず方向（トークン）→ 最重要の2図 → 残りのページ、の順で進む。

## 中身

| ファイル | 役割 |

| `06-参考サイトと方向性.md` | まつりと／日本遺産ポータルの実地分析 |
| `現状コード/` | 問題のある実装と現行 `tokens.css` |

## 9つの課題（要約）

| # | 内容 | 重さ |
|---|---|---|
| 1 | 全体が単調。四角形が多すぎる | ★ |
| 2 | 俯瞰マトリクスが数値表にすぎない | ★★ |
| 3 | 記事本文の横幅が狭すぎる（目次と欄外注は残す） | |
| 4 | 不適切な出典の削除 → **対応済み。設計対象外** | |
| 5 | トップの年表（1200–1877）がだめ | ★ |
| 6 | 「家と家格」ページがだめ | ★★ |
| 7 | 年表がテキストだけ。2〜3項目ごとに図版を | |
| 8 | 「人物と家」を索引に徹させ、家ごとの詳細ページ＋地図へ | ★★ |
| 9 | 職制図と家格ピラミッドを作り直す（図表の水準の見本） | ★★ |
