# 参考サイトと方向性

サイト運営者が挙げた2つの参照先を、実際にソースを読んで分析したもの。

---

## 1. まつりと — https://matsurito.jp/

**「白背景の硬質な内容でありながら、誰もが見やすいと思える本格的なデザイン」**
として挙げられた。デザインの目標水準。

### 技術的に分かったこと

- **Astro + Svelte アイランド**で作られている（`hoisted.*.js` と `/assets/` の命名から）。
  こちらと同じ土俵なので、移植の相性が非常に良い
- 書体：**Zen Kaku Gothic New 400/700 のみ**。欧文書体を足していない
- 配色（実際のCSSから抽出した値）

  | 役割 | 値 |
  |---|---|
  | 地 | `#fff` |
  | 文字 | `#212223`（純黒ではない） |
  | 罫線 | `#e1e5e9` |
  | 弱い文字 | `#21222340`（黒の25%） |
  | アクセント | `#fa3f3d` `#ffe560` `#35db62` `#3cd2fa` |

- `--transition-cue: 0 / 1 / 2 …` というカスタムプロパティで、
  **出現アニメーションの遅延を要素ごとに段階指定**している。
  この手法はこちらでも `--cue` として取り込み済み

### 学ぶべき点

- 白地＋ほぼ黒の二値を土台にして、**アクセントは高彩度を少量**だけ使う
- 罫線が非常に淡い（`#e1e5e9`）。囲うのではなく、**仕切る**
- 写真を主役にし、文字は写真を邪魔しない位置に置く

### そのまま真似できない点

まつりとは**写真が主役**のサイト。こちらは現時点で**写真が0点**であり、
主役になるのは図表と文章。「写真の代わりに何が画面を持たせるのか」を
設計しなければならない。ここが今回の最大の勝負どころ。

## 2. 日本遺産ポータル — https://japan-heritage.bunka.go.jp/ja/

**`class="box_sto"` のような、写真や図をもとに視覚的に興味のあるものを
見つけやすい仕組み**として挙げられた。機能の目標水準。

### `box_sto` の実体

構造を読むと、こうなっている。

```
.box_sto
├─ #js-storyMain   主パネル（大きな画像＋番号＋見出し＋リード＋本文）
└─ #js-storyList
    ├─ 「気になる地域のコラムをクリック！」という誘い文句
    └─ #js-back   サムネイル一覧（画像＋題名＋番号＋リード）
```

サムネイルをクリックすると、**ページ遷移せずに主パネルの中身が差し替わる**。
「一覧から気になるものを選ぶ → その場で詳しく見る」という往復ができる。

### そのほかの仕掛け

| 機能 | 実装 |
|---|---|
| スクロール出現 | `.scrollActive` クラスの付け外し |
| 流れ続ける画像帯 | `infiniteslidev2` |
| カルーセル | slick-carousel 1.8.0 |
| クリックできる地図 | `imageMapResizer`（画像＋イメージマップ） |
| 地域選択 | 8地域の重ね画像（`layer_map.png`）をクリック |
| 絞り込み | 都道府県のセレクトボックス |

### 注意

**jQuery 3.4.1 に依存している。** こちらでは使わない。
同じ体験は既に依存ゼロで実装済み（`現状コード/StoryBrowser.astro`）。
**発想を借り、実装は借りない。**

### 学ぶべき点

- 「探す」ことを**作業ではなく誘い**にしている（"Click!" の吹き出し、誘い文句）
- 一覧と詳細を同一画面に置き、行き来のコストをゼロにしている
- 番号（#009 のような通し番号）が、コレクションを集めている感覚を作っている

## このサイトが取るべき方向

上の2つを足すだけでは足りない。このサイト固有の事情がある。

### 事情1 — 写真がない

当面、画面を持たせるのは**自作の図**。だから

- 図が「本文の添え物」ではなく**主役**として設計されている必要がある
- 図のない箇所をどう見せるかも設計対象（ごまかさない）

### 事情2 — 学術的な誠実さが売り

出典・信頼度・諸説の併記・欠損の明示が、このサイトの価値そのもの。
これらは**目立ちすぎても、隠れすぎてもいけない**。
「ちゃんとしている」という手応えが伝わる程度に、常に視界の端にある状態が理想。

### 事情3 — 密度が高い

家格11段、役職12、年表25件（将来は数百）、記事115本。
**情報が多いことを、多いまま気持ちよく見せる**必要がある。
減らして整えるのは逃げ。

### 事情4 — 題材の性質

武家の制度・身分・軍制という題材。
軽薄な装飾やポップな配色は合わない。
かといって古めかしい「和風テンプレート」も違う。
**現代的で、硬質で、密度が高く、それでいて読みやすい**——という難しい線を狙う。

> 運営者の言葉：
> 「一般的な日本史をよく知る人に対して、もっと詳細な佐賀藩のすべての情報を
> 800ページもあるような書籍を何冊も読まないと分からないようなものを、
> サイトとして情報を取捨選択し、図表などを入れてわかりやすくし、
> さらに Web サイトだからできる様々な複雑な機能を大いに活用する」
