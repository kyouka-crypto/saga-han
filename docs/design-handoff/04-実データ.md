## 家格序列 — 11段（課題6・9に使う）

- **久保田村田家** … 親類三家のひとつ。

- **須古鍋島家** … 龍造寺一門四家のひとつ。
- **武雄鍋島家** … 龍造寺一門四家のひとつ。独自に大砲の鋳造を行うなど独立した軍備を持ち、戊辰戦争で活躍した。
- **多久家** … 龍造寺一門四家のひとつ。多久安順らが佐賀の多久屋敷で執務し「請役所」と称したことが、藩の最高行政機関の名称の起源とされる。

人物の要約（カードに入る実際の文字量）：

- **鍋島直茂** … 龍造寺氏の重臣から実権を握り、鍋島氏による佐賀支配の基礎を築いた。今山合戦の夜襲で知られる。藩主の代数を直茂から数えるか勝茂から数えるかで、以後の代数が1つずれる。
- **鍋島勝茂** … 直茂の子。三部上地による知行地没収で集権化を完成させ、手明鑓の身分を創設し、島原の乱後には長崎警備を課された。佐賀藩の骨格はこの治世に形づくられた。
- **鍋島光茂** … 「御代始条目」を発布し、その第一条に長崎警備を規定した。「長崎御番ハ在陣同然」と認識していたという。山本常朝が仕えた藩主でもある。
- **鍋島治茂** … 明和九年に藩政改革を開始し、天明元年に藩校弘道館を設立した。安永九年から七ヵ年にわたる徹底した倹約政治（「安永子丑」）を敷いた。文化二年一月没。19歳のとき支藩鹿島藩主となっている。
- **鍋島斉直** … 治世四年目の文化五年八月、佐賀藩が長崎警備の当番年にあたっていたときにフェートン号事件が起きた。文政八年頃からは藩政を家老に一任するようになったという。
- **鍋島直正** … 藩政改革を断行し、反射炉・精煉方・三重津海軍所を擁して西洋技術導入の最前線を築いた。佐賀藩を幕末の軍事技術先進藩へ押し上げた人物。
- **鍋島直大** … 佐賀藩最後の藩主。戊辰戦争に藩兵を率いて参加し、版籍奉還・廃藩置県を迎えた。
- **山本常朝** … 光茂に仕えた藩士。その談話を田代陣基が筆録したものが『葉隠』である。
- **江藤新平** … 初代司法卿。明治七年の佐賀の乱を率いて敗れ、処刑された。
- **龍造寺隆信** … 「五州二島の太守」と称された戦国大名。肥前を統一し九州北部に勢力を広げたが、天正十二年の沖田畷の戦いで島津・有馬連合軍に敗れ戦死した。

各機関の説明（図中や吹き出しに入れうる実文）：

- **案文方** … 文書の作成を担当した。文書行政が独立の機能として組み込まれている点に、藩政運営の文書主義がうかがえる。
- **着到** … 佐賀藩の軍事組織。番方の編成を中世的な呼び方で「着到」と称した。整備された段階では家臣を15組（御側4・先手2・警固6・留守居3）に分けた。三支藩・親類・親類同格は本藩とは別に独自の着到を持っていた。
- **代官** … 郡代のもとで村方を掌握した。
- **郡代** … 地方支配の要。明和年間の治茂の藩政改革期には、その職掌や存在意義が不明確になっていたという。
- **懸硯方** … 御蔵方と並ぶ別会計。請役所はこの二重会計を監督した。
- **御蔵方** … 藩財政の一般会計を担当した。
- **御目安方** … 銀蔵・米蔵の管理を担当した。
- **大組頭** … 着到15組の責任者。横岳・神代・深堀・太田・倉町・姉川の各鍋島家の家老の家格と、のち着座一八家と呼ばれる着座の中から選ばれるのが原則であった。
- **相談役** … 請役家老を補佐した。
- **附役** … 請役所の実務を補助した。
- **請役家老（御当役）** … 請役所の実務を主宰した藩政の最高責任者。原則として龍造寺一門の親類同格四家（諫早・武雄・多久・須古）から交代で任じられた。
- **請役所** … 藩政を総括した最高行政機関。名称は多久安順らが佐賀の多久屋敷で執務し「請役所」と称したことに始まる。
